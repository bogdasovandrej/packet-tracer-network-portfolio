# Три офиса и OSPF

Начни с `guide.docx`. Схема и точная портовая карта приведены там же. В `configs/` — команды для R-HQ, R-B1, R-B2. Коммутаторы в этой лаборатории работают с VLAN 1 по умолчанию и специальной конфигурации не требуют.

Контроль: два соседа OSPF на каждом маршрутизаторе; три DHCP-аренды; ping между офисами; обходной путь через B2 после `shutdown` HQ G0/1; возврат прямого маршрута после `no shutdown`. Результаты надо подтвердить в `.pkt`.
