# Cisco Packet Tracer network portfolio

Три учебных проекта для начинающего сетевого инженера. Руководства написаны по-русски для Cisco Packet Tracer 9.0 и объясняют не только команды, но и ожидаемые результаты, диагностику и оформление доказательств.

| Проект | Содержание | Материалы |
|---|---|---|
| [1. Сеть благотворительного центра](project-01-charity-center/) | VLAN, trunk, router on a stick, DHCP, NAT, ACL, SSH, DNS и HTTP | Word-руководство, схема, команды |
| [2. Три офиса](project-02-three-offices/) | OSPF area 0, центральный DHCP, relay, отказ и восстановление WAN | Проверенный `.pkt`, Word-руководство, схема, команды |
| [3. Пять инцидентов](project-03-incident-lab/) | Ошибки VLAN, trunk, DHCP relay, OSPF и ACL | Word-руководство и исправления |

## Статус воспроизведения

Руководства и эталонные CLI-команды готовы. Для проекта 2 добавлен собранный в Packet Tracer 9.0 `.pkt`; выполнены проверки DHCP, OSPF, ICMP и переключения маршрута. Для проектов 1 и 3 `.pkt` ещё не добавлены; они пока являются учебными планами и наборами команд. Ожидаемые результаты в документах не выдаются за проведённые измерения. Перед использованием проект 2 стоит открыть заново и повторить проверки из руководства.

## Как учиться

Начать с проекта 1. После каждого этапа запустить указанную проверку, записать вывод и разобраться в причине отличия. Затем выполнить проект 2 и проверить переключение маршрута. Для проекта 3 копировать исправный baseline, вносить по одной ошибке и вести карточку расследования. Решение следует сразу после сценария, поэтому сначала сформулировать диагноз самостоятельно.

## Публикация результатов

После выполнения добавить в каждый каталог исходный `.pkt`, снимки из своей симуляции в `evidence/` и краткий отчёт о тестах. Не публиковать реальные пароли: `YOUR_PASSWORD` в командах проекта 1 — заглушка. Не включать в репозиторий установщик Packet Tracer или чужие учебные файлы.

## На собеседовании

Начни с задачи и схемы, затем назови свой вклад и три проверяемых факта. Для проекта 2: «Связал три офиса треугольником из трёх маршрутизаторов, настроил OSPF area 0 и DHCP relay. Все ПК получили адреса из своих подсетей, соседства OSPF перешли в FULL, при отключении прямого канала HQ–B1 маршрут к 10.20.1.0/24 переключился с 10.255.12.2 на 10.255.13.2». Покажи `.pkt`, `show ip ospf neighbor`, `show ip route` и повтори тест. Для проектов 1 и 3 говори о них как о разработанных лабораториях, пока не воспроизведёшь их в симуляторе.
