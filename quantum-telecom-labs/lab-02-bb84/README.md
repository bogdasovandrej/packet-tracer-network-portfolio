# Лабораторная 2. BB84

Запуск: `python -m lab02.bb84 --pulses 100000 --intercept` из `quantum-telecom-labs`. Полный разбор — в `guide.docx`. Исходник: `../lab02/bb84.py`.

Программа считает просеянные биты и QBER. Коррекция ошибок, усиление секретности, аутентификация классического канала, конечный размер блока и аппаратные несовершенства **не реализованы**; полученная строка не является готовым безопасным ключом.
