# Лабораторная 1. Оптическая линия

Запуск: `python -m lab01.link_budget` из `quantum-telecom-labs`. Подробные шаги, объяснение каждой формулы, задания и вопросы для собеседования находятся в `guide.docx`. Исходник: `../lab01/link_budget.py`.

Ключевая граница модели: инженерный запас входит в плановый бюджет, но не прибавляется к физическим потерям при расчёте вероятности регистрации. Полученные регистрации и QBER — приблизительные учебные оценки, **не скорость секретного ключа**.
