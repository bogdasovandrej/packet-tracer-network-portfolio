# Практикум по квантовым телекоммуникациям

Три связанные лабораторные для начинающего инженера. Всё запускается локально на Python без внешних библиотек. Физические параметры и QKD протоколы здесь **моделируются**; код не создаёт квантовый канал и не предназначен для защиты настоящих секретов.

## Порядок работы

1. [Оптическая линия](lab-01-optical-link/) — бюджет потерь, вероятность регистрации, QBER и запас линии.
2. [BB84](lab-02-bb84/) — подготовка и измерение битов, просеивание базисов, шум, перехват и статистика.
3. [Сервис ключей](lab-03-key-service/) — архитектура приложения и менеджера ключей, ETSI-подобный REST API, очередь ключей и отказы.

В каждом каталоге находятся исходный код, тесты, подробное руководство Word и пример вывода. Запускайте команды из корня этого каталога:

```powershell
python -m unittest discover -s tests -v
python -m lab01.link_budget
python -m lab02.bb84
python -m lab03.demo
```

Word-руководства можно воспроизвести скриптом `tools/build_guides.py`. Для него отдельно нужны `python-docx` и `Pillow` из `tools/requirements-docs.txt`; сам лабораторный код использует только стандартную библиотеку Python.

Совет для обучения: прочитайте постановку в Word, сделайте прогноз результата до запуска команды, затем сравните вывод с прогнозом. Меняйте один параметр за раз и фиксируйте объяснение. На собеседовании показывайте собственный запуск и честно называйте ограничения модели.

## Источники и границы

- [ETSI GS QKD 014](https://www.etsi.org/deliver/etsi_gs/QKD/001_099/014/01.01.01_60/gs_qkd014v010101p.pdf) — формат API выдачи ключей. Третья лаборатория повторяет учебные идеи и некоторые имена маршрутов, но не заявляет полную совместимость.
- [ITU-T Y.3802](https://www.itu.int/rec/T-REC-Y.3802-202012-I) — роли узлов, управления ключами и приложения.
- [ITU-T Y.3806](https://www.itu.int/rec/dologin_pub.asp?id=T-REC-Y.3806-202109-I%21%21PDF-E&lang=e&type=items) — метрики качества, включая скорость генерации ключей и QBER.
- [SeQUeNCe](https://github.com/sequence-toolbox/SeQUeNCe) — следующий шаг для более детального моделирования квантовых сетей.

QKD и постквантовая криптография — разные подходы. Для изучения программно разворачиваемой постквантовой криптографии см. [NIST FIPS 203 ML-KEM](https://csrc.nist.gov/pubs/fips/203/final).
