# Лабораторная 3. Сервис выдачи ключей

Запуск: `python -m lab03.demo` из `quantum-telecom-labs`. Подробное руководство — в `guide.docx`. Исходники: `../lab03/service.py`, `../lab03/demo.py`.

Сервис запускается только на 127.0.0.1. `X-SAE-ID` — демонстрационный идентификатор, **не аутентификация**. HTTP вместо HTTPS, нет QKD оборудования, защищённого хранения, key distillation и полной совместимости с ETSI GS QKD 014. Не используйте ключи из этого стенда для реальной защиты информации.
