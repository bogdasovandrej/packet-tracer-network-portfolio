# Пять инцидентов

Подробные сценарии и решения — в `guide.docx`; короткие исправления — в `fixes/`. Кейсы 1, 2 и 5 требуют исправного проекта 1, кейсы 3 и 4 — исправного проекта 2. Для каждого кейса нужна отдельная копия `.pkt` с ровно одной неисправностью, исходный вывод команд, причина и проверка после ремонта.

Сейчас `.pkt` и реальные evidence не добавлены. Не называй кейсы завершёнными до их воспроизведения.
