# Сеть благотворительного центра

Начни с `guide.docx`. Схема — `topology.png`. Файлы в `configs/` содержат последовательность ввода для ручной настройки и не являются автоматически снятым `show running-config`.

Контроль: VLAN и trunk; адреса DHCP; внутренний сайт для администратора и волонтёра; запрет внутреннего сервера гостю; внешний учебный сервер через NAT; SSH только из сети администратора. Фактические результаты будут добавлены после сборки `.pkt`.

## Практическое применение

Такой дизайн полезен небольшой организации с общим доступом в интернет, внутренним порталом и отдельными ролями сотрудников, волонтёров и гостей. VLAN разделяют устройства на сегменты, ACL формулирует правило доступа, NAT даёт выход наружу, а DHCP и DNS снижают объём ручной настройки. На собеседовании объясни поток одного пакета от гостевого ПК до сервера и покажи, где именно ACL его остановит. Пока `.pkt` не собран, это проектный замысел и подготовленные команды, а не подтверждённый результат.
